# IAM Personas

## Human Identities

| Persona | Responsibility|
|---------|---------------|
|Developer| Develop and maintain code|
|Tester | Test the application code|
|Security engineer | Security assessment and monitoring of the application and infrastructure|
| Devops Engineer | Plan, Design, Develop, Deploy and monitor the infrastructure as well as CI/CD of the application in all the environments|

## Workload identities

| Identity | Responsibility|
|----------|---------------|
| CI Pipeline| Build, Test and publish the application artifacts|
| ArgoCD | Deploy application using GitOps in all environments|
| Monitoring | COllect the application and Platform logs and metrics|
